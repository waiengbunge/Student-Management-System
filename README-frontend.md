Frontend build (Vite + Bootstrap + SASS)

Quick start (requires Node.js >=16):

1. Install dependencies:

```bash
npm install
```

2. Development (hot reload):

```bash
npm run dev
```

3. Build production assets (writes to static/dist):

```bash
npm run build
```

Add the built files to your Django templates (e.g. include /static/dist/main.js and built CSS).
